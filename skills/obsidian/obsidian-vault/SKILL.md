# Obsidian Vault

Obsidian Vault のノートを作成、移動、改名、編集するときに従う。Vault 以外の Markdown には適用しない。

## 1. Vaultレイアウト

- vaultは以下の階層構造を基本とする：

```
📁 00-Inbox/          # 保存先が未確定なノートの一時保管場所
📁 01-Daily/          # 日記・日々の記録
📁 02-Projects/       # 進行中のプロジェクト
📁 03-Areas/          # 継続的な責任領域（仕事、健康、学習など）
📁 04-Resources/      # 参考資料、テンプレート
📁 05-Archive/        # 完了したプロジェクトや古いノート
📁 99-Templates/      # ノートテンプレート
```

### ファイル命名規則

- 日記ノートは `YYYY-MM-DD-タイトル.md`
- 分野別ノートは番号プレフィックス（例: `01-数学`, `02-物理`）
- vault全体で一貫した命名パターンを使用する
- 分野固有ノートには日本語ファイル名も使用可（例: `加法定理.md`）

### 数学ノートの構造

- `## 概要` から開始
- `## 基本的な公式` を適切なコードブロックで含める
- `## 導出方法` を追加
- `## 応用例` を含める
- `## まとめ` で終了

### テンプレートの使用

- `99-Templates/` にテンプレートを作成し、必要に応じてフロントマターを含める

## 2. ワークフロー

### ノート作成フロー

1. 保存目的が明確な新しいノートは、目的に応じたフォルダへ直接作成する
2. 保存先が未確定なノートのみ `00-Inbox/` で作成する
3. 必要に応じて `99-Templates/` から適切なテンプレートを使用する
4. `00-Inbox/` のノートは、内容が固まったら目的に応じて以下のフォルダに移動する：
   - 日記・ログ系 → `01-Daily/`
   - 進行中プロジェクト → `02-Projects/`
   - 継続的な学習・研究 → `03-Areas/学習/` 以下
   - 参考資料・ガイド・公式 → `04-Resources/`
   - 完了したプロジェクト → `05-Archive/`

### 日次ノート

- `01-Daily/` に日次ノートを作成
- 形式は `YYYY-MM-DD.md`
- その日のタスク、思考、学習ログなどを記録する

### プロジェクト管理

- 各プロジェクトは `02-Projects/` 配下にフォルダを作成して管理する
- 完了したプロジェクトは `05-Archive/` に移動してアーカイブする

### 学習・研究ノート

- `03-Areas/学習/` 配下に分野別フォルダ（例: `数学`, `統計`, `プログラミング`）を作成して整理する

### リソース管理

- 参考資料やガイドは `04-Resources/` に保存する
- 種類別（公式・参考文献・ガイドなど）にサブフォルダやタグで整理する

## 3. Markdownフォーマット

### 見出しと構造

- ノートタイトル用の `#` は使用せず、メインセクションには `##` を使用する
- サブセクションには `###`
- さらに細かい階層には `####` を使用する

### 数学コンテンツ

- 数式は必ずLaTeX形式で書く
  - インライン数式: `$...$`
  - 独立行の数式: `$$...$$`
- 分数は `\frac{分子}{分母}`、累乗は `^` を用いて明確に記述する
- `\(...\)` や `\[...\]` などのLaTeX形式は使用せず、Markdown数式の `$...$` / `$$...$$` に統一する
- 表内の数式が長い場合は 1 行に詰め込まず、`\\` で改行して読みやすくする
  - 必要に応じて `\begin{aligned} ... \end{aligned}` を使い、`&=` で整列する
- 連鎖等式（`A=B=C` のような式）は適切に改行し、複数行の場合は `aligned` で縦位置を揃える
  - 例:
    - `\begin{aligned}`
    - `a &= b \\`
    - `&= c`
    - `\end{aligned}`

### リンクと参照

- 内部リンクには `[[ノート名]]` を使用する
- 外部リンクには `[表示テキスト](URL)` を使用する
- 必ず意味のあるリンクテキストを付ける

### タグ

- タグはノート末尾にまとめて記載する
- `#` プレフィックスを使用し、一貫した命名を守る：
  - `#数学`, `#三角関数`, `#公式`
  - `#学習`, `#プロジェクト` など必要な分類タグ

### フロントマター（任意）

- フロントマターを使う場合はYAML形式に統一する：

```yaml
---
title: "ノートタイトル"
tags: [数学, 三角関数]
created: 2024-01-01
---
```

## その他

- ノートを作成時にリンクチェックは必要ない
