# Obsidian 用語集執筆スキル

## 目的

- 用語集は、**最初の1〜2文で意味が入ること** を最優先にする。
- 詳細版でも、**教科書の再現** ではなく、**読者が最初に理解できる説明** を書く。
- 正確さは保ちつつ、**専門用語は後から出す**。

## 基本ルール

- レイヤ分けは **`## シンプル版` / `## 詳細版`** などの見出しで行う。
- 用語見出しは **`### 用語名`** とする。
- 同じノートに併記する場合も、**シンプル版の直下に詳細版の長文を混ぜない**。
- ノート末尾に用語タグをまとめる運用なら、新規用語を足したときだけ **対応する用語タグ** を追記する。

## いちばん大事な書き方

- **最初の1文は一般人向けに書く。**
- 書き出しは「これは何を判断するものか」「何を見るためのものか」から始める。
- いきなり「定義」「自由度」「帰無仮説」「母分散未知」から入らない。
- まず **意味**、次に **なぜそう見るのか**、必要なら最後に **式** の順にする。

良い出だしの例:

```markdown
### t検定
- 2つのグループの平均に、意味のある差があるかを判断する方法。
```

避けたい出だしの例:

```markdown
### t検定
- 母分散未知の正規母集団における検定統計量で...
```

## シンプル版

### 方針

- **1〜2文、長くても3文まで。**
- まず「何のための用語か」を平易に書く。
- 必要なら短い言い換えを1つだけ添える。
- 式は基本入れない。入れても **1行の軽い触れ方** にとどめる。

### テンプレート

```markdown
### 用語名
- [何を見るためのものかを、やさしく一文で]
- [必要なら、言い換えや補足を一文]
```

### 例

```markdown
### t検定
- 2つのグループの平均に、意味のある差があるかを見るための方法。
- 平均の差を、データのばらつきと比べて判断する。
```

## 詳細版

### 方針

- 詳細版でも **長くしすぎない**。基本は **3ブロック** で十分。
- 構成は **一般論 → 理論の核 → 必要なら式・使いどころ** を標準とする。
- 数式は「大事なら1つだけ」。本文の流れの中で自然に出す。
- 「対比」「誤解」「関連」「計算量」は、**本当に必要なときだけ** 足す。

### 標準構成

1. **一般論**  
   まず、その用語が何を判断する道具かを普通の言葉で説明する。

2. **理論の核**  
   なぜそれで判断できるのかを、専門用語を増やしすぎずに 1〜3 文で説明する。

3. **式・使いどころ（必要なら）**  
   重要な式を 1 つだけ入れ、何を表す式かを短く添える。使う場面も 1〜2 個で十分。

### テンプレート

```markdown
### 用語名
- [まず、何を見るためのものかをやさしく一文で]

**理論の核**
- [なぜそれで判断できるのかを 1〜3 文で]

**式・使いどころ（必要なら）**
- [式の意味を一言]
- $$ ... $$
- [どんな場面で使うかを短く]
```

### 例

```markdown
### t検定
- 2つのグループの平均に、意味のある差があるかを判断する方法。

**理論の核**
- 平均の差が大きく見えても、データのばらつきが大きければ偶然かもしれない。
- そこで、平均の差をばらつきで割って、「差の大きさが偶然の範囲を超えているか」を見る。

**式・使いどころ**
- 平均の差を標準誤差で割った値を見る。
- $$ t = \frac{\text{平均の差}}{\text{標準誤差}} $$
- A/Bテスト、授業法の比較、薬の効果比較などで使う。
```

## 省略のルール

- 用語集なので、**全部入りにしない**。
- 次の要素は **必要なときだけ** 書く: 対比、仮説、厳密定義、密度関数、関連ノート、計算量。
- 迷ったら、**短い方を選ぶ**。
- 「これがないと誤解する」場合だけ補足を足す。

## チェックリスト

- [ ] 最初の1文だけで、何の用語かだいたい分かる
- [ ] 専門用語から始まっていない
- [ ] 詳細版でも、一般論から入っている
- [ ] 数式を入れるなら 1 つで足りるか確認した
- [ ] 項目を増やしすぎて、用語集というより解説記事になっていない
- [ ] シンプル版と詳細版が見出しで分かれている
- [ ] 末尾タグ運用のノートなら、用語タグだけを必要に応じて更新した

## やらないこと

- いきなり厳密定義から始める
- セクションを増やしすぎる
- 数式を何個も並べる
- 正しいが読みにくい教科書調の文を優先する
